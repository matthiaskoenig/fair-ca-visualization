# Using the app

The app has four tabs.

## About

The motivation of the FAIR COMBINE Archive Indicators, how to cite the app, and an example of the **Model** and **Model metadata** indicators of the `BioModels_C19_curated` assessment.

## Assess Model

Assess your own model:

1. Download the template with **Download FAIR Template**.
2. Fill in the column `Assessment` for every indicator, see [Assessing a model](assessment.md).
3. Upload the filled template with **Upload FAIR model assessment**.

The app shows the FAIR percentage per category as a bar plot, one polar bar plot per type of indicator (Model, Model metadata, Archive, Archive metadata), and the table of the assessment. A file which is not a filled template, or an assessment value other than empty, 0, 0.5 or 1, is reported as an error naming the column or the indicator.

The uploaded file is only processed in the running app and not stored.

## Example Assessments

The assessments bundled with the app, e.g., curated and non curated models of BioModels and the Physiome Model Repository and published pharmacokinetic models. Select a model to show the same plots as for an uploaded assessment.

## Indicators

All indicators of the template with their identifier, type, category, priority and description. The column **FAIR Assessment** shows how many of the example assessments rate the indicator as NA, 0, 0.5 and 1.
