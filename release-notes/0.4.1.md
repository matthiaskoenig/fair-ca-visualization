# Release notes for fair-ca-visualization 0.4.1

We are pleased to release the next version of fair-ca-visualization, which fixes the deployment of the app.

## Fixes
- the app on Streamlit Community Cloud failed to start with 0.4.0: the uv of Community Cloud could not parse `uv.lock`, which had no version of the package; the version is now static in `pyproject.toml` and recorded in `uv.lock`

## Development
- a release is only created from a tag on `develop`
- documentation: wrapped entries of the API table of contents are indented
- updated dependencies and GitHub Actions
