# Release notes for fair-ca-visualization 0.4.0

We are pleased to release the next version of fair-ca-visualization, the first one available as a python package on PyPI.

## Features
- python package `fair-ca-visualization` on PyPI with the template and the example assessments bundled; `uv tool install fair-ca-visualization` and `fairvis` start the app locally (#8)
- the app reports an uploaded file which is no valid FAIR assessment, e.g., missing columns or values other than NA, 0, 0.5 and 1, instead of failing
- example assessments are listed in alphabetical order
- documentation at https://matthiaskoenig.github.io/fair-ca-visualization

## Fixes
- the "Report a bug" link of the app points to this repository
- empty unnamed columns of assessment files are no longer shown
- `.zenodo.json` declared the LGPL-3.0 license, the code is MIT licensed

## Development
- tests with pytest, including a headless run of the app and a run from the installed wheel
- linting and formatting with ruff, type checking with ty, pre-commit hooks
- continuous integration and releases with GitHub Actions, publishing to PyPI by trusted publishing
- repository rulesets, `develop` as default branch, `main` tracks the latest release
- `CITATION.cff`, `AGENTS.md`
- `requirements.txt` is removed, Streamlit Community Cloud installs from `uv.lock`
