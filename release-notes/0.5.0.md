# Release notes for fair-ca-visualization 0.5.0

We are pleased to release the next version of fair-ca-visualization with a review of the app for performance, security and usability.

## Features
- NA (not applicable) is distinguishable from 0: the polar bar plots draw an NA indicator as a full gray bar (#1)
- the FAIR percentage of a category counts only the applicable indicators, NA no longer counts as not fulfilled (#1)
- the bar plot shows the percentages on the bars and the number of fulfilled and applicable indicators on hover
- every tab, and the selected example model, has its own link, e.g. `?tab=Example+Assessments&model=PMR_curated`
- the **Indicators** tab counts the example assessments with NA, 0, 0.5 and 1 in one column each
- the **Assess Model** tab explains the three steps of an assessment
- the publication of the FAIR COMBINE Archive Indicators in npj Systems Biology and Applications is cited in the app, the documentation, `CITATION.cff` and `.zenodo.json` (#7)
- the layout works on phones: no fixed side margins, a smaller title, labels of the polar bar plots inside the figure
- the FAIR-CA logo is the icon of the app; the menu links to the documentation instead of an email address

## Performance
- only the selected tab is computed
- the figures of the example assessments are computed once and cached
- an uploaded file is parsed once per session, not on every interaction

## Security
- uploads are limited to 1 MB, 20 MB unpacked and 1000 rows, which rejects zip bombs; the xml of an upload is parsed with defusedxml, which protects against xml bombs
- an upload is rejected if it misses indicators of the template, has unknown indicators or has an indicator more than once
- an unreadable file is reported without the internal error message of the parser, an unexpected error without the traceback
- an upload is cached only in the session of the user, never shared between users
- dependencies are updated to the latest versions, among them urllib3 2.8.0 with fixes of five vulnerabilities; pandas 3 is supported

## Development
- the options of `fairvis` and `.streamlit/config.toml` are tested to agree
- the app tests select tabs through the query parameters and test the upload of valid and invalid files
