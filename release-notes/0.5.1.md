# Release notes for fair-ca-visualization 0.5.1

We are pleased to release the next version of fair-ca-visualization, which fixes the table of the indicators.

## Fixes
- the **Indicators** tab showed 39 empty columns `Unnamed: 11` to `Unnamed: 49`: the xlsx reader of 0.5.0 padded every row to the limit of 50 columns; a sheet is now read with its own columns, as with `pandas.read_excel` (#21)

## Development
- the columns read from the template and every example assessment are tested to agree with `pandas.read_excel`
